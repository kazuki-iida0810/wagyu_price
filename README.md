# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- リモートリポジトリはネット上に配置して複数人で共有するためのもの
- ローカルリポジトリは自分のPC上にで作業するもの

## プッシュとマージの違いは何でしょうか？

- プッシュはローカルにコミットされた状態のをリモートにアップする意味
- マージは分岐したブランチを統合すること

## コミットとプッシュの違い

- コミットは変更履歴を今いるブランチに保存することができる
- プッシュはローカルのコミットしたらリモートにアップする意味

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 誰が見ても、変更した内容と意図が瞬時にわかること

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- ローカルは手元のパソコンのターミナルでブランチを統合する
- GitHubやGitLabなどのWeb上で変更したところをマージして欲しいとリクエストを作成し、他の方がデビューを行い、承認することでマージをする。

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

1. コンフリクトしたファイルをVSCodeで開き該当する部分を確認
1. 双方の変更内容を見比べ、該当者の方と話して、どちらにするかを決めて、選ばれなかったのは全て削除する
1. 修正終えたらファイルを保存してターミナルでaddしてcommitをし完了する
