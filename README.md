# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

- リモートリポジトリはネット上に配置して複数人で共有するためのもの
- ローカルリポジトリは自分のPC上にで作業するもの

## プッシュとマージの違いは何でしょうか？

- プッシュはローカルで出来た内容をリモートに反映する意味
- マージは最新のブランチを現在いるブランチに取り込むことができる

## コミットとプッシュの違い

- コミットはセーブのようなもの。過去のコミット地点に戻れること
- プッシュはローカルで出来た内容をリモートに反映する意味

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 変更した時にどこを変えたのかを書いてあげるのが最適だと思います

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- ローカルはコードデビューは自分の判断
- プルリクエストは他の方に見てもらい確認してもらう

## コンフリクトを起こしてしまった場合、どう対処すべきですか？

1. 先にマージされた変更内容を取り込む
1. 後にマージしようとしている変更内容を取り込む
1. どちらの変更内容を取り込む
- 三つの取り込み作業が終えたらコンフリクト作業で行なった解決をコミットしてあげる
